# Chance-of-Admission-for-Higher-Studiess

## Project Objective
To predict the probability of admission to a graduate program using machine learning techniques based on students' academic performance.

## Approach
- Load the dataset
- Preprocess the data
- Perform Exploratory Data Analysis (EDA)
- Train the regression model
- Predict admission chances
- Evaluate model performance

## Dataset
- Dataset Name: Admission Chance Dataset
- Source: Kaggle

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
